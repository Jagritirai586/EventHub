# 🎟️ EventHub - Event Booking Website

A modern, responsive Event Booking Website built using **HTML, CSS, and JavaScript**. EventHub allows users to explore upcoming events, search and filter events, view event details, switch between light and dark mode, and book tickets through an interactive booking form.

---

## 🌟 Features

- 🎟️ Browse Featured Events
- 🔍 Search Events by Name
- 🎯 Filter Events by Category
- 🌙 Dark / Light Mode Toggle
- 💾 Theme Preference Saved using Local Storage
- 📋 Show / Hide Event Details
- 📝 Booking Form with Validation
- ✅ Booking Confirmation with User Details
- ⏳ Dynamic Event Countdown
- 📌 Active Navigation Highlight
- ⬆️ Scroll-to-Top Button
- 📱 Fully Responsive Design
- ⭐ Customer Testimonials
- 📊 Website Statistics Section
- 💡 "Why Choose EventHub" Section
- 🦶 Professional Footer with Contact Information

---

## 🚀 How to Run the Project

1. Clone this repository

```

```

2. Open the project folder.

3. Open **index.html** in your browser.

No additional installation is required.
